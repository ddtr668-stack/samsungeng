Apps Script 코드 복사

[전체 복사]를 누르면 파일 전체가 클립보드에 들어갑니다. Apps Script 편집기에서 해당 파일을 Ctrl+A → Ctrl+V 로 통째로 바꾸고, 마지막 줄 번호가 아래 줄 수와 같은지 확인하세요.

  1. 파일마다 [전체 복사] → Apps Script 편집기의 같은 이름 파일에서 Ctrl+A → Ctrl+V → 저장(Ctrl+S)
  2. 편집기 맨 아래 줄 번호가 위 "줄 수"와 같은지 확인 (다르면 잘린 것)
  3. 배포 → 배포 관리 → ✏️ → 버전 "새 버전" → 배포 ("새 배포" 아님)
