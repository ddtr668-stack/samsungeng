  삼성이엔지 계약관리 대시보드 · 내 PC 서버 설치판
═══════════════════════════════════════════════════════════════

【 실행 방법 · 딱 한 줄 】

  ▸ Windows        →  "서버_실행_Windows.bat"  더블클릭
  ▸ macOS / Linux  →  "서버_실행_Mac.command"  더블클릭
  ▸ 어디서든 (Python)  →  "서버_실행_Python.py"  더블클릭 또는
                          터미널에서 `python 서버_실행_Python.py`

  3초 뒤 브라우저가 자동으로 열리며 http://localhost:3000 이 표시됩니다.


───────────────────────────────────────────────────────────────
【 사전 준비 · 최초 1회만 】
───────────────────────────────────────────────────────────────

  다음 중 하나만 설치되어 있으면 됩니다 (Node.js 를 권장):

    · Node.js LTS   https://nodejs.org
    · Python 3      https://www.python.org/downloads/
                    (Windows 설치 시 "Add Python to PATH" 반드시 체크)

  ▶ 설치 후 컴퓨터를 재부팅하면 실행 스크립트가 자동으로
    설치된 프로그램을 찾아냅니다.


───────────────────────────────────────────────────────────────
【 첫 실행 후 · 스프레드시트 연결 】
───────────────────────────────────────────────────────────────

  1. 좌측 메뉴에서 [설정] 클릭

  2. "Google Apps Script 웹앱 URL" 에 배포 주소 붙여넣기 → 저장
     ↓
     구글 스프레드시트 → 확장 프로그램 → Apps Script
     → 배포 → 배포 관리 → 활성 배포의 URL 복사

  3. "연결된 스프레드시트" 에 시트 URL 붙여넣기 → 저장

  4. (선택) "Google Drive API 인증 정보" 에 API Key + Client ID 등록
     → 현장 자료 폴더가 실시간으로 표시됩니다


───────────────────────────────────────────────────────────────
【 GAS 백엔드 · 현장설치정보 저장 활성화 】
───────────────────────────────────────────────────────────────

  최근 추가된 "현장설치정보" 저장을 사용하려면 Apps Script 재배포가
  필요합니다. `gas-backend/PATCH_EDITABLE_FIELDS.gs` 파일의 내용을
  기존 DashboardApi.gs 의 `var EDITABLE_FIELDS_ = { ... };` 블록과
  통째로 교체 후 "배포 관리 → 새 버전" 으로 재배포하세요.


───────────────────────────────────────────────────────────────
【 서버 중단하는 방법 】
───────────────────────────────────────────────────────────────

  · 실행된 검은 창(터미널)을 닫거나 Ctrl+C
  · 창을 닫아도 사이트는 켜져 있지만, 새로고침 시 표시되지 않습니다


───────────────────────────────────────────────────────────────
【 자주 발생하는 문제 】
───────────────────────────────────────────────────────────────

Q. 실행 시 "Node.js 또는 Python이 설치되어 있지 않습니다"
A. 위 "사전 준비" 항목을 확인하세요. Windows 는 설치 후 재부팅 권장.

Q. 브라우저가 "이 사이트에 연결할 수 없음" 이라 나옴
A. 검은 창이 아직 서버 시작 중일 수 있습니다. 5초 뒤 새로고침.
   또는 포트 3000 이 다른 프로그램에 사용 중일 수 있으니
   서버_실행_Python.py 상단의 `PORT = 3000` 을 다른 숫자로 변경.

Q. Mac 에서 "확인되지 않은 개발자" 경고
A. Finder 에서 파일 우클릭 → "열기" → 팝업의 "열기" 재선택 (1회만).

Q. 시트 저장이 안 됨
A. 설정 화면에서 GAS 웹앱 URL 이 등록되어 있는지, 그리고 위
   "GAS 백엔드" 항목의 재배포가 완료됐는지 확인하세요.
